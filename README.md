# 運気の女神 ✨ Lucky Girl Oracle

15占術を統合した日々の鑑定から、その日の「運気の女の子」をAI生成するデイリー占いPWA。
ビルド不要の静的サイトで、`index.html` を開くだけで動作します。

## ファイル構成

| パス | 役割 |
| --- | --- |
| `index.html` | アプリ本体（HTML / CSS / 占いエンジン / 画像生成をすべて内包） |
| `manifest.json` | PWAマニフェスト（名前・テーマ色・アイコン） |
| `sw.js` | Service Worker（アプリシェルのキャッシュとオフライン起動） |
| `assets/icons/` | アプリアイコン（192 / 512 / maskable / apple-touch） |
| `assets/splash/` | iOS起動スプラッシュ。ファイル名は `<幅>x<高>.png` |
| `assets/ai/` | 端末内AI超解像（TensorFlow.js・Real-CUGAN/Real-ESRGAN）と端末内生成（onnxruntime-web）。ライセンス同梱 |
| `diag.html` | 実機診断（端末内生成が動くかを判定） |

## 占術エンジン

暦はすべて端末内の天文計算で求めます（通信不要・年の範囲制限なし）。

| 区分 | 内容 |
| --- | --- |
| 天文暦 | 太陽黄経 = VSOP87短縮版（誤差 約1分）／朔 = Meeus第49章（誤差1分未満） |
| 暦 | 二十四節気・旧暦（閏月含む）・六曜・月齢（JST正午）。ajnet実測暦415日分と全項目一致 |
| 東洋 | 四柱推命（年月日時柱・通変星・天中殺）／九星気学（本命星・月命星・年盤・月盤・日家）／紫微斗数 |
| 西洋 | 月星座／上昇星座（出生図：1993-04-14 06:18 JST・横浜で固定） |
| その他 | タロット（日付ハッシュで毎日独立に1枚）／数秘術／五行ラッキーカラー |

## 画像生成

クレジットやAPIキーが無くても、最新世代の **FLUX.1** と **端末内AI超解像** で高精細な画像を作ります。

| 順 | 生成元 | 条件 | 解像度 |
| --- | --- | --- | --- |
| 1 | Pollinations（キー付き） | APIキー設定時のみ | モデル依存（〜1536×2304） |
| 2 | **無料FLUX（Hugging Face Spaces）** | 既定ON・キー不要 | 1024×1536 ネイティブ |
| 3 | Pollinations 無料 | 上が失敗/無料GPU枠切れ | 約627×940 |
| 4 | Stable Horde（SDXL → SD1.5） | 最終手段 | 832×1216 |
| 📴 | **端末内生成（Tiny SD・オフライン）** | モデル保存時。「常に使う」なら最初、「自動」ならオフライン時は最初・オンライン時は Pollinations 無料の後 | 448×640 → AI超解像 |

| 画質モード | 生成 | 仕上げ |
| --- | --- | --- |
| ⚡ 高速 | FLUX.1 schnell 768×1152 | 等倍 |
| ⚖ バランス | FLUX.1 schnell 1024×1536 | 低解像度ソースのみAI超解像で1536pxへ |
| 💎 高画質 | FLUX.1 dev（28step）1024×1536 | Real-CUGAN 2x で 2048×3072 |

- 無料FLUXは Hugging Face の無料GPU枠（ZeroGPU）を使います。枠を使い切ると自動で次の経路へ切り替わり、回復時刻まで呼びません。
  無料アカウントの Read トークン（`hf_…`）を設定すると枠が増えます（料金はかかりません）。
- AI超解像は `assets/ai/` の TensorFlow.js と学習済みモデル（Real-CUGAN: MIT／Real-ESRGAN: BSD-3）を
  端末のGPU（WebGPU → WebGL）で実行します。モデルは初回のみ読み込み IndexedDB に保存されます。
  画像はまず原寸で表示し、超解像が終わると高解像度版に差し替わります。

### 📴 端末内生成（通信なし）

⚙設定でモデル（標準 約0.95GB／軽量 約0.60GB）を一度だけダウンロードすると、機内モードでも、
無料枠やAPIが切れていても、端末のGPU（WebGPU）だけで生成できます。

- 実行: onnxruntime-web（WebGPU）。部品を1つずつ読み込み・解放してメモリを節約（iPhone 15 Pro の実機診断: 1ページ約1.9GBが上限）
- 保存: OPFS（Worker で書き込み・途中再開・SHA-256 検証）
- 写真調が得意。プロンプトは英語向き（CLIP の 77トークンまで）
- 実機診断ページ: `diag.html`

APIキー類はブラウザの localStorage にのみ保存され、生成リクエスト以外には送られません。

生成した画像はブラウザの IndexedDB に保存されます（非★は最大200件）。
直近20件と★お気に入りはフル解像度も保持し、ギャラリーから原寸のまま保存・共有できます。

## 動作確認

```sh
python3 -m http.server 8000   # → http://localhost:8000
```

Service Worker と `navigator.share` は `https://` もしくは `localhost` でのみ有効です。
